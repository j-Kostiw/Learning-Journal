🔹 Software Development Life Cycle (SDLC)
Describes stages of software projects

Agile: iterative, flexible, suitable for time-sensitive applications

Waterfall: linear, sequential

XP (Extreme Programming):

Small teams, rapid changes

Emphasizes coding, communication through code

Practices: frequent testing, daily design, short iterations

🔹 Python Basics
Syntax vs. Semantics: form vs. meaning

Typing:

Dynamic: type is inferred

Strong: cannot mix incompatible types without conversion

Functions:

Defined with def, return values with return

Functions always return a value (default is None)

🔹 Boolean Logic & Control Flow
True/False, logical operators: and, or, not

if, elif, else for conditionals

Ternary expression: x = a if condition else b

assert: for debugging and checks

🔹 Loops
For loops:

Iterate over strings, lists, dictionaries, etc.

range(n) = [0, 1, ..., n-1]

Multiple assignment possible in tuples: for x, y in [(a, 1), (b, 2)]

List Comprehensions:

[x*2 for x in list if x > 0]

Cleaner, more Pythonic way to build lists

While loops: loop until condition becomes false

🔹 Google Colab
Hands-on with Python in notebooks

Easy way to explore code without installing Python locally

🔹 Software Testing
Goal: bug-free, performant software matching expectations

Testing Types:

Unit Testing

Integration Testing

System Testing

Test Planning: plan for QA activities like defect tracking, code reviews

🔹 Python Unit Testing
Use the unittest module

Automate testing of individual functions/modules

Helps detect bugs early and maintain reliable code

🔹 Knowledge Check Highlights
XP focuses on continuous testing/integration, not waterfall

Python’s unittest is for test construction and execution

None behaves like False in logical expressions
