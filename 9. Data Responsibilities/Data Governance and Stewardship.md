13. Distinction-Level EPA Answer (Model Response)
Question:

“How would you design and implement a data governance framework for an organisation handling sensitive customer data?”

Model Answer (Distinction Level)

I would design a data governance framework that integrates roles, policies, processes, and technology to ensure data is accurate, secure, and compliant.

Firstly, I would define clear roles and responsibilities. A Chief Data Officer would oversee governance strategy, Data Owners would be accountable for datasets, Data Stewards would maintain data quality, and Data Custodians would manage infrastructure. This ensures accountability and prevents issues being overlooked.

Secondly, I would establish policies and procedures. Policies would define what must be done, such as enforcing encryption and data minimisation, while procedures would specify how to implement these, for example using AES-256 encryption and role-based access controls. This ensures consistency and compliance with regulations such as GDPR.

Next, I would implement data stewardship principles, focusing on data quality, security, and lifecycle management. This would include validation at ingestion, continuous monitoring, and automated correction processes to maintain data integrity across systems.

I would also introduce technology solutions, such as data catalogues for visibility, monitoring tools for data quality, and automated governance tools to enforce policies. Metrics such as data quality scores and ownership coverage would be used to measure effectiveness.

Finally, I would ensure continuous improvement by regularly auditing governance processes, identifying gaps, and updating policies based on evolving business and regulatory requirements.

This approach ensures that data is not only technically managed but also trusted, compliant, and aligned with business objectives, reducing risk while enabling effective decision-making.

Why This Hits Distinction
Covers full system design
Links technical + governance + business impact
Includes justification and trade-offs
Demonstrates K + S + B together
