Data Visualisation, Storytelling & Chart Design

Sources:

1. Big Picture: What You Are Learning

This module is about transforming data into useful, actionable insights through:

Visualisation (charts, dashboards)
Storytelling (communication + narrative)
Design principles (how humans interpret visuals)
Core Idea

Data engineering is not just about building pipelines — it’s about delivering insights that people can understand and act on.

3. Identifying the Key Message (NEW – Chart Design Deck)

From page 2:

“It’s not the audience’s job to derive insight from an unnecessarily complicated graph.”

3.1 What This Means
You must decide the message before building the chart
Avoid expecting users to “figure it out”
3.2 How to Identify the Key Message (page 3)
Step 1: Define Purpose
What question are you answering?

Example:

Relationship between income and health outcomes
Step 2: Filter Data
Only include:
Relevant data
Accurate data
3.3 Practical Rule

One chart = one clear message

6. Gestalt Principles (NEW – Visual Perception)

From pages 9–10.

6.1 Key Idea

The brain naturally looks for:

Patterns
Structure
Groupings
6.2 Main Principles
1. Proximity
Items close together are seen as related
2. Similarity
Similar colours/shapes are grouped
3. Continuation
The eye follows smooth paths
4. Connectedness
Linked elements are perceived as related
6.3 Why This Matters
Poor layout → confusion
Good layout → intuitive understanding
6.4 Practical Example

Grouping charts in a dashboard:

Related metrics should be close together
Use consistent colours for categories

Minimal clutter
Clear titles

Easy to read?
Logical layout?

Understandable for non-technical users?

12. Exam / Assignment Tips
When Building Visualisations:
Start with the question
Define one key message
Choose the right chart type
Use colour intentionally
When Designing Dashboards:
Group related visuals (Gestalt)
Highlight key metrics (pre-attentive attributes)
Keep layout simple
When Presenting:
Use storytelling structure
Focus on 1–3 insights
End with a clear recommendation
