🧱 Types of Big Data Structures
Data Type	Characteristics	Examples
Structured	Row & column format	SQL, CSV
Semi-structured	Some structure, but flexible	JSON, XML
Unstructured	No predefined format	Images, videos, social media posts

Structured is easiest to process.
Unstructured is richest, but hardest to handle.

🧠 Data Structure in Action
Think of a spreadsheet:

Structured: Name, Age, Species

Semi-structured: JSON objects with varied keys

Unstructured: A video of your cat, or tweets about it 🐱

🗂️ Cloud Big Data Storage Options
You'll usually choose between:

Data Warehouses (structured analytics)

Data Lakes (raw storage, flexible types)

Or a hybrid (Lakehouse)

Benefits & Drawbacks:
Storage Type	Benefit	Drawback
Data Warehouse	Optimized for SQL analytics	Expensive, less flexible
Data Lake	Handles all data types	Harder to query directly

🧭 Ethics in Big Data
Key legal frameworks:

DPA 2018

GDPR (EU/UK)

💡 If it can identify a person, it’s personal data.

Data Type	Example
Non-personal	Anonymous company revenue
Personal	Name, IP address, email
Sensitive	Ethnic background, health info

⚠️ GDPR Compliance: 7 Principles
Lawfulness, fairness, transparency

Purpose limitation

Data minimisation

Accuracy

Storage limitation

Integrity & confidentiality

Accountability

⚠️ Non-compliance can cost up to €20M or 4% of global turnover.

🛡️ Secure-by-Design: Key Takeaways
Use pseudonymisation and encryption.

Be clear about why you’re processing data.

Limit access and duration of data retention.

Respect user rights (access, erasure, objection).
