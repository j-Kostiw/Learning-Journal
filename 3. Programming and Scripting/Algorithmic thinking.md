🧠 Key Concepts & Notes
🔁 What is an Algorithm?
A step-by-step procedure to solve a problem or perform a task.

Can be likened to a recipe (e.g., chocolate chip cookies example).

Composed of:

Data (inputs)

Instructions (steps)

🧮 Algorithms in Real Life
Education: Adaptive learning platforms use algorithms to adjust difficulty.

Search Engines: Google's PageRank determines page relevance based on links.

Everyday Products: Shampoo bottle instructions as a flawed loop example.

🧩 Components of an Algorithm
Data structures – store information

Instructions – operations to modify data

Conditionals – decision-making (if/else)

Control structures – sequence, loops

Modules – logical grouping (abstraction)

🧰 Properties of a Good Algorithm
Clear: Easy to understand

Efficient: Uses minimal resources

Correct: Solves the problem accurately

Deterministic: Same output for same input

Finite: Always terminates

🧠 Abstraction
Hides complexity, focuses on general ideas.

Examples: variables, functions, pseudocode, programming languages.

Helps simplify and modularize algorithms.

🧾 Pseudocode & Flowcharts
Used for planning and reasoning about algorithms.

Emphasizes logic and structure without worrying about syntax.

🔄 Programming = Algorithmic Thinking + Syntax Knowledge
Understanding logic comes first.

Syntax is needed to implement logic in a programming language.

💬 Input/Output (I/O)
read() and print() used in pseudocode for interaction.

I/O allows communication between the user and algorithm.

📈 Algorithm Analysis
Concerned with computational performance and efficiency.

Use Big-O Notation to express complexity:

O(1), O(logN), O(N), O(N logN), O(N²), O(2^N)

Sorting Algorithm Comparison:
Insertion Sort: O(N²) – inefficient for large datasets.

Merge Sort: O(N logN) – much more scalable.
