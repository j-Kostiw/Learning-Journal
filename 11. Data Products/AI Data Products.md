1. Big Picture: What Are AI-Enabled Data Products?
1.1 Definition

AI-enabled data products are systems that:

Use data + machine learning models
Deliver predictions, automation, or recommendations
Operate within data pipelines or applications
1.2 Core Idea

AI turns data from “descriptive” (what happened) into “predictive and prescriptive” (what will happen / what to do).

1.3 Real-World Example (IBM Watson – page 3)
Challenge: Large-scale patient data + accurate diagnosis
Solution: AI model analysing medical data
Impact:
Improved diagnosis accuracy
Personalised healthcare
Insight

AI adds value by improving decision quality at scale

2. Core AI & Machine Learning Concepts
2.1 What is AI vs ML? (page 8)
AI:
Simulates human intelligence
Decision-making, reasoning
ML:
Learns patterns from data
Improves without explicit programming
2.2 Types of Machine Learning
1. Supervised Learning
Uses labelled data
Example: predicting house prices
2. Unsupervised Learning
Finds hidden patterns
Example: customer segmentation
3. Reinforcement Learning
Learns via reward/feedback
Example: recommendation engines, robotics
2.3 Key Misconception

From page 8:

“AI must be trained from scratch” → False
Reality:
You can:
Use pre-trained models
Fine-tune existing models
Use APIs

5. AI Integration Approaches (Activity 2)

From pages 12–13:

5.1 Three Main Approaches
1. Pre-trained Models via API
Fastest
Low effort
Example: OpenAI, AWS AI APIs

Pros:

Quick deployment
No training required

Cons:

Less control
Limited customisation
2. AutoML
Automated model building

Pros:

Easy to use
No deep ML expertise needed

Cons:

Less transparency
Limited optimisation
3. Fine-Tuning Pre-trained Models
Customise existing models

Pros:

Better performance
Tailored to business

Cons:

Requires data + expertise
5.2 Full Custom Model Development
Build from scratch

Best for:

Complex, high-value use cases
5.3 Comparison Criteria (page 13)
Accuracy
Speed
Ease of use
Business value
Key Insight

Choose the simplest approach that delivers sufficient value
